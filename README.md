# 주짓수 타이머 웹앱

iPhone과 iPad에서 바로 사용할 수 있는 스파링 타이머입니다. 별도 서버나 계정이 필요 없는 정적 웹앱입니다.

## 사용

1. 웹앱 주소를 Safari에서 엽니다.
2. `소리 확인`으로 기기 음량을 확인한 뒤 `시작`을 누릅니다.
3. 홈 화면에 두려면 Safari 공유 메뉴에서 **홈 화면에 추가**를 선택합니다.

처음 방문 후에는 오프라인에서도 열 수 있습니다. 소리와 화면을 계속 사용하려면 타이머 화면을 켜 둡니다. 화면 잠금이나 앱 전환이 감지되면 타이머가 일시정지됩니다.

## 기능

- 큰 타이머, 스파링은 검은색·휴식은 빨간색
- 빠른 설정: 4분/30초, 5분/1분, 8분/1분 30초
- 스파링 30초~10분 선택, 11~99분 직접 입력, 휴식 0~2분 30초
- 메인 화면에서 반복 횟수 변경, 또는 종료 시각으로 횟수 자동 계산
- 시작·휴식·다음 스파링·전체 종료 비프음
- 마지막 스파링 뒤 휴식 없이 종료, 종료 시각 전에 시작한 스파링은 끝까지 진행

## 개발 확인

```sh
node --test
python3 -m http.server 8000
```

두 번째 명령을 실행한 뒤 `http://localhost:8000`을 열면 됩니다. 파일을 직접 열면 오프라인 캐시가 등록되지 않습니다.
